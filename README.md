A program that writes one original sentence (160 characters) to convince a friend who has never coded to let an AI agent build their first app idea on make.fun: offer to type the idea in once, and the only thing the friend risks is finding out it was possible all along.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
